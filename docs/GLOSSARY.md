# Product and Technical Glossary

| Istilah | Definisi |
|---|---|
| Master | Pengguna administratif dengan akses pengelolaan LMS sesuai permission |
| Pelajar | Pengguna yang mengikuti learning path dan course |
| Learning Path | Rangkaian course yang diarahkan pada tujuan kompetensi tertentu |
| Course | Program pembelajaran yang terdiri dari beberapa module |
| Module | Kelompok lesson dalam satu course |
| Lesson | Unit pembelajaran terkecil |
| Enrollment | Hubungan akses Pelajar terhadap Course |
| Lesson Progress | Status pembelajaran pada satu lesson |
| Course Progress | Agregasi progress seluruh required lesson |
| Continue Learning | Rekomendasi lesson terakhir atau berikutnya |
| Learning Goal | Tujuan utama pengguna belajar |
| Learning Event | Event perilaku yang digunakan untuk analytics |
| Drop-off | Kondisi pengguna berhenti atau tidak melanjutkan setelah titik tertentu |
| Risk Score | Skor rule-based untuk mengidentifikasi risiko pengguna berhenti belajar |
| Active Learner | Pengguna dengan aktivitas pembelajaran valid dalam tujuh hari |
| Inactive Learner | Pengguna tanpa aktivitas pembelajaran valid lebih dari tujuh hari |
| Discussion | Topik forum pada course, module, atau lesson |
| Announcement | Pengumuman dari Master kepada target pengguna |
| Notification | Pesan personal atau sistem untuk pengguna |
| Audit Log | Catatan administratif atau tindakan privileged |
| Modular Monolith | Satu aplikasi backend dengan module domain yang memiliki batas tegas |
| Outbox | Table event yang ditulis dalam transaksi yang sama dengan business data |
| Idempotency | Sifat operasi yang aman dijalankan ulang tanpa menghasilkan efek ganda |
| Read Model | Data hasil agregasi yang dioptimalkan untuk pembacaan |
| RPO | Maksimum kehilangan data yang dapat diterima |
| RTO | Maksimum durasi pemulihan layanan yang dapat diterima |
| ADR | Architecture Decision Record |
| P0 | Wajib untuk core MVP |
| P1 | Penting setelah core MVP |
| P2 | Pengembangan lanjutan |
