# Architecture Decision Records

## Rules

- Satu keputusan penting memiliki satu ADR.
- ADR tidak diedit untuk menyembunyikan sejarah.
- Keputusan yang diganti diberi status `Superseded`.
- ADR baru harus menyebut ADR yang digantikan.
- Hanya ADR `Accepted` yang menjadi dasar implementasi.

## Status

- `Proposed`
- `Accepted`
- `Rejected`
- `Superseded`
- `Deprecated`
